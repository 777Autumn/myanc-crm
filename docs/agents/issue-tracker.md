# Issue tracker

Use this private repository's existing GitHub remote and `gh` for issues/PRs.
The user-approved current spec is `docs/real-crm-trial.md`; it implements the
single-Owner trial plan from the current task. Do not create duplicate issues or
publish real CRM data. Scope review to the fixed baseline recorded in that spec.

Push/merge is authorized only after required reviews and CI. This does not
authorize real CRM switching; that requires separate user confirmation.
